## Research

### Role-dependent susceptibility of LLM agents to social engineering

*Does the role we give an agent change which persuasion tactics work against it?*

- **Design:** one agent in three roles, a corporate, a personal and a peer assistant, on the same task, tested under four conditions: pressure, emotional closeness, reasoning and reciprocity, and a no-tactic control
- **Method:** 13-category codebook, blind independent coding of 20% of conversations with a target Krippendorff's α ≥ 0.70, OSF pre-registration
- **Platform:** Next.js, TypeScript, Supabase, automated end-to-end tests with Playwright
- **Status:** pilot in November 2026, data collection from December 2026
- **Supervisor:** Assoc. Prof. Gülsüm Zeynep Gürkaş Aydın
